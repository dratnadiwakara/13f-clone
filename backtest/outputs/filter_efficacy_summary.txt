FILTER EFFICACY — full Compustat universe, disaster avoidance
======================================================================

Question: does each quant filter avoid BAD companies? Not: does it
pick winners. Primary metric is the rate of severe drawdown
(return < -50%) in the REJECTED cohort minus the ACCEPTED
cohort. Positive delta = the filter is rejecting worse companies.

Returns: Compustat prcc_f/ajex, fiscal-year to fiscal-year,
dividend-blind (biases AGAINST the filters). Delisted firms are
classified by dlrsn and retained, never dropped.
Bankruptcy (dlrsn 02) forced to -100%: True
CIs: cluster bootstrap over gvkey, 1000 draws.

  H= 1y: 97,458 firm-years, 13,723 firms, severe-dd base rate 7.7%, failure base rate 0.5%
  H= 3y: 82,636 firm-years, 12,557 firms, severe-dd base rate 14.4%, failure base rate 1.3%
  H= 5y: 67,855 firm-years, 11,066 firms, severe-dd base rate 17.1%, failure base rate 2.1%
  H=10y: 35,895 firm-years, 8,393 firms, severe-dd base rate 20.6%, failure base rate 3.1%

size/sector-matched delta keeps the same sign, and the sign holds
